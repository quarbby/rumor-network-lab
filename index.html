The same belief rule in all four approaches

Every human starts by rejecting the rumor with a score of zero. Each delivered rumor message adds one; each counter-rumor message subtracts one. At the end of a step, a score of at least +3 means acceptance, and a score of at most −3 means rejection. Between those thresholds, the previous belief persists. The threshold control changes both limits.

A bot sends to its assigned humans; a human sends to every network neighbor. All belief changes happen together at the end of a step. We complete all 20 steps, even if everyone accepts earlier. A run that stops before step 20 has no observed count for step 20.

Model runs execute in Node.js, where credentials remain local. This page runs Approach 1 or displays saved outputs from the four approaches. It never simulates model responses.
